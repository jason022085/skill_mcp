## 2025-06-23 - [O(1) Path Exclusion Checks]
**Learning:** During deep directory traversals for file scanning, replacing string-based path exclusions (`f"/{excluded}/" in str(path)`) with `set.isdisjoint(path.parts)` for simple directory names is highly effective and safer. The `isdisjoint` check provides O(1) subset checks and is roughly 2-3x faster without altering the original path filtering semantics. Note that it requires explicit casting of the exclusion collection to a set/frozenset to avoid AttributeError, and complex exclusions (those containing slashes) still need a string-check fallback.
**Action:** When filtering paths with `pathlib.Path`, prioritize `set.isdisjoint(path.parts)` for simple exclusions, retaining string checks only for complex multi-segment exclusions. Avoid swapping `pathlib.Path.glob()` with `os.walk` to avoid semantic regressions.
