## 2026-04-28 - Fast Path Filtering and Traversal
**Learning:** For path exclusion logic checking against a set of disallowed components, using `set.isdisjoint(path.parts)` provides O(1) performance and is significantly faster than using substring checks on `str(path)`. Similarly, checking dot-prefixes via `any(part.startswith('.') ...)` is faster than full iteration. Additionally, when discovering large sets of files where only string path relationships are needed, `os.walk` paired with string manipulation and slicing is multiple times faster than `pathlib.Path.rglob()`, avoiding the substantial overhead of heavy `Path` object instantiations.
**Action:** When filtering paths based on deep path hierarchies, use `path.parts` intersecting over string operations on the full path. When needing to recursively find and list file paths without `Path` API usage, prefer using `os.walk` instead of `pathlib.Path.rglob()`.
