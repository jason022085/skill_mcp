## 2025-03-01 - Optimize Path Exclusion Logic with isdisjoint
**Learning:** Using `set.isdisjoint(path.parts)` provides an efficient O(N) subset check (where N is the number of path parts) and is significantly faster than iterating through a list of excluded strings and performing `in` substring checks on `str(path)`. Additionally, while linters often suggest `any()` generator expressions for loops, a standard `for` loop is actually faster in CPython due to the overhead of creating generator objects and calling `next()`.
**Action:** Use `set.isdisjoint()` for path-based filtering logic against sets instead of iterating and checking string representations of paths. Prefer basic `for` loops over `any()` with generator expressions in performance-critical code paths despite linter warnings (e.g., SIM110).
