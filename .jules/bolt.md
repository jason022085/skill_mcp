## 2025-05-18 - Deep Directory Traversal and Filtering Performance
**Learning:** For deep directory traversals where only string paths are needed, `os.walk()` is significantly faster than `pathlib.Path.rglob()` (approximately 8x faster in benchmarks). This is because `os.walk()` avoids the heavy instantiation overhead of `Path` objects. Additionally, when filtering paths to exclude specific directories, checking subset overlap with `set.isdisjoint(path.parts)` is drastically faster (`O(N)`) than checking for string substrings `f"/{excluded}/" in str(path)` (`O(N*M)`).
**Action:** Prefer `os.walk` with string manipulation and `os.path.relpath()` for performance-critical directory scanning operations when `Path` object methods aren't strictly required. Use `set.isdisjoint(path.parts)` for path exclusion checks over iterative substring scanning.
