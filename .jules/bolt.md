## 2025-02-28 - Optimize directory scanning exclusion logic
**Learning:** For path-based filtering or exclusion logic using `pathlib.Path`, using `set.isdisjoint(path.parts)` for efficient subset checks is significantly faster than performing substring checks on `str(path)`. The string substring check `f"/{excluded}/" in path_str` is slower and can fail on relative paths depending on platform and formatting. `isdisjoint` offers an O(1) checking mechanism against a set of excluded single-level directory names. Note that it will not match nested paths natively (e.g. `env/lib`).
**Action:** Replace string-based exclusion logic in deep directory traversals with `set.isdisjoint` on path parts whenever the excluded directories represent simple, single-level names. Combine with a regular `for` loop for any additional part-level logic (e.g., hidden files) to avoid generator overhead in performance-critical paths.
