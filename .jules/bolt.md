## 2025-06-03 - os.walk vs pathlib.Path.rglob Performance
**Learning:** For deep directory traversals (like file scanning), `pathlib.Path.rglob("*")` can become a massive performance bottleneck because it yields `Path` objects for every file and directory, and doesn't allow easy in-place pruning of excluded directories. This means hidden directories or excluded paths (like `.git` or `node_modules`) will be fully traversed even if their files are ignored later.
**Action:** Prefer using `os.walk` in performance-sensitive file scanning paths. It avoids `Path` instantiation overhead for every entry and allows pruning directories in-place (`dirs[:] = [d for d in dirs if not d.startswith('.')]`), significantly reducing the number of I/O operations in deep/large directory structures.
